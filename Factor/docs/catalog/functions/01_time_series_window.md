## 算子详细规格卡片

### <a id="decay"></a> `decay(x1, window)`

- **功能说明**：完整窗口内的滚动算术均值。
- **所属分类**：`time_series` (时序窗口)
- **输入形状契约**：`float64 [T × S] （日期 × 股票）`
- **输出形状契约**：`float64 [T × S]（date × code）`
- **滑动窗口要求**：必须指定正整数 window
- **缺失值与非有限值处理 (NaN / Inf)**：统计时跳过 NaN，不自动剔除 Inf；没有非 NaN 样本则返回 NaN。显式滚动窗口不足时返回 NaN，不用更短窗口代替。

**参数列表**：

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :---: | :--- |
| `x1` | `matrix` | 是 | `-` | 待计算的 Feature 或表达式矩阵。 |
| `window` | `integer` | 是 | `-` | 正整数观测行数，包含当前行；省略时按整段输入时间轴归约，会改变输出轴。日频一行是一个交易日，不是自然日。 |

**调用示例与数值映射**：
```text
decay(x1,3)
输入 x1：[[1, 2, NaN, 4], [2, 2, 3, 8], [3, 0, 6, 4], [4, 6, 3, 12]]
输出：[[NaN, NaN, NaN, NaN], [NaN, NaN, NaN, NaN], [2, 1.33333, 4.5, 5.33333], [3, 2.66667, 4, 8]]
```

### <a id="dense_rank_ts"></a> `dense_rank_ts(x1)`

- **功能说明**：在输入的时间序列窗口内执行稠密排名。
- **所属分类**：`time_series` (时序窗口)
- **输入形状契约**：`float64 [T × S] （日期 × 股票）`
- **输出形状契约**：`float64 [T × S]（date × code）
从 1 开始的整数名次；普通排名按有限样本数计，稠密排名按不同有限值数计；NaN 除外。`
- **滑动窗口要求**：无需滑动窗口
- **缺失值与非有限值处理 (NaN / Inf)**：仅排列有限值；NaN/Inf 位置为 NaN。相同数值共用名次，后续不同数值名次连续；不要求标准差非零，常数有限序列的原始稠密名次为 1。

**参数列表**：

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :---: | :--- |
| `x1` | `matrix` | 是 | `-` | 待计算的 Feature 或表达式矩阵。 |

**调用示例与数值映射**：
```text
dense_rank_ts(x1)
输入 x1：[[1, 2, NaN, 4], [2, 2, 3, 8], [3, 0, 6, 4], [4, 6, 3, 12]]
输出：[[1, 2, NaN, 1], [2, 2, 1, 2], [3, 1, 2, 1], [4, 3, 1, 3]]
```

### <a id="emadecay"></a> `emadecay(x1, window)`

- **功能说明**：按旧到新 1..N 权重线性加权的滚动衰减，不是指数衰减。
- **所属分类**：`time_series` (时序窗口)
- **输入形状契约**：`float64 [T × S] （日期 × 股票）`
- **输出形状契约**：`float64 [T × S]（date × code）`
- **滑动窗口要求**：必须指定正整数 window
- **缺失值与非有限值处理 (NaN / Inf)**：NaN 所在位置权重剔除，剩余权重重新归一化。

**参数列表**：

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :---: | :--- |
| `x1` | `matrix` | 是 | `-` | 待计算的 Feature 或表达式矩阵。 |
| `window` | `integer` | 是 | `-` | 正整数观测行数，包含当前行；省略时按整段输入时间轴归约，会改变输出轴。日频一行是一个交易日，不是自然日。 |

**调用示例与数值映射**：
```text
emadecay(x1,3)
输入 x1：[[1, 2, NaN, 4], [2, 2, 3, 8], [3, 0, 6, 4], [4, 6, 3, 12]]
输出：[[NaN, NaN, NaN, NaN], [NaN, NaN, NaN, NaN], [2.33333, 1, 4.8, 5.33333], [3.33333, 3.33333, 4, 8.66667]]
```

### <a id="pct_rank_ts"></a> `pct_rank_ts(x1)`

- **功能说明**：在整段输入时间历史内对每只股票的所有时点做稳定百分位排名，输出整段矩阵。
- **所属分类**：`time_series` (时序窗口)

**参数列表**：

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :---: | :--- |
| `x1` | `matrix` | 是 | `-` | 待计算的 Feature 或表达式矩阵。 |

**调用示例与数值映射**：
```text
pct_rank_ts(x1)
输入 x1：[[1, 2, NaN, 4], [2, 2, 3, 8], [3, 0, 6, 4], [4, 6, 3, 12]]
输出：[[0.25, 0.5, NaN, 0.25], [0.5, 0.75, 0.333333, 0.75], [0.75, 0.25, 1, 0.5], [1, 1, 0.666667, 1]]
```
