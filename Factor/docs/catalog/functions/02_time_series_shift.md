## 算子详细规格卡片

### <a id="ts_delta"></a> `ts_delta(x1, period)`

- **功能说明**：计算当前值减去 period 个周期前的值。
- **所属分类**：`time_series_shift` (时序位移)
- **输入形状契约**：`float64 [T × S] （日期 × 股票）`
- **输出形状契约**：`float64 [T × S]（date × code）`
- **滑动窗口要求**：无需滑动窗口
- **缺失值与非有限值处理 (NaN / Inf)**：当前或移位后的值为 NaN 则结果为 NaN；越界部分为 NaN。period=0 返回 x1-x1（有限值为 0），以 C++ 运行时为准。

**参数列表**：

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :---: | :--- |
| `x1` | `matrix` | 是 | `-` | 待计算的 Feature 或表达式矩阵。 |
| `period` | `integer` | 否 | `1.0` | 带符号整数观测行数：正数取历史、负数取未来，零不移位。 |

**调用示例与数值映射**：
```text
ts_delta(x1,1)
输入 x1：[[1, 2, NaN, 4], [2, 2, 3, 8], [3, 0, 6, 4], [4, 6, 3, 12]]
输出：[[NaN, NaN, NaN, NaN], [1, 0, NaN, 4], [1, -2, 3, -4], [1, 6, -3, 8]]
```

### <a id="ts_pct_chg"></a> `ts_pct_chg(x1, period)`

- **功能说明**：计算相对 period 个周期前数值的变化率。
- **所属分类**：`time_series_shift` (时序位移)
- **输入形状契约**：`float64 [T × S] （日期 × 股票）`
- **输出形状契约**：`float64 [T × S]（date × code）`
- **滑动窗口要求**：无需滑动窗口
- **缺失值与非有限值处理 (NaN / Inf)**：当前值/历史值缺失或越界为 NaN；历史值绝对值 <1e-6 时为 NaN。

**参数列表**：

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :---: | :--- |
| `x1` | `matrix` | 是 | `-` | 待计算的 Feature 或表达式矩阵。 |
| `period` | `integer` | 否 | `1.0` | 带符号整数观测行数：正数取历史、负数取未来，零不移位。 |

**调用示例与数值映射**：
```text
ts_pct_chg(x1,1)
输入 x1：[[1, 2, NaN, 4], [2, 2, 3, 8], [3, 0, 6, 4], [4, 6, 3, 12]]
输出：[[NaN, NaN, NaN, NaN], [1, 0, NaN, 1], [0.5, -1, 1, -0.5], [0.333333, NaN, -0.5, 2]]
```

### <a id="ts_roll"></a> `ts_roll(x1, period)`

- **功能说明**：沿时间轴循环移位，首尾环绕。
- **所属分类**：`time_series_shift` (时序位移)
- **输入形状契约**：`float64 [T × S] （日期 × 股票）`
- **输出形状契约**：`float64 [T × S]（date × code）`
- **滑动窗口要求**：无需滑动窗口
- **缺失值与非有限值处理 (NaN / Inf)**：不补 NaN；被移出的尾部值会回到开头。

**参数列表**：

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :---: | :--- |
| `x1` | `matrix` | 是 | `-` | 待计算的 Feature 或表达式矩阵。 |
| `period` | `integer` | 是 | `-` | 带符号整数观测行数：正数取历史、负数取未来，零不移位。 |

**调用示例与数值映射**：
```text
ts_roll(x1,1)
输入 x1：[[1, 2, NaN, 4], [2, 2, 3, 8], [3, 0, 6, 4], [4, 6, 3, 12]]
输出：[[4, 6, 3, 12], [1, 2, NaN, 4], [2, 2, 3, 8], [3, 0, 6, 4]]
```

---

### <a id="ts_shift"></a> `ts_shift(x1, period)`

- **功能说明**：沿时间轴移动 period 行，移入部分填 NaN。
- **所属分类**：`time_series_shift` (时序位移)
- **输入形状契约**：`float64 [T × S] （日期 × 股票）`
- **输出形状契约**：`float64 [T × S]（date × code）`
- **滑动窗口要求**：无需滑动窗口
- **缺失值与非有限值处理 (NaN / Inf)**：正 period 开头填 NaN；负 period 会读取未来行。

**参数列表**：

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :---: | :--- |
| `x1` | `matrix` | 是 | `-` | 待计算的 Feature 或表达式矩阵。 |
| `period` | `integer` | 是 | `-` | 带符号整数观测行数：正数取历史、负数取未来，零不移位。 |

**调用示例与数值映射**：
```text
ts_shift(x1,1)
输入 x1：[[1, 2, NaN, 4], [2, 2, 3, 8], [3, 0, 6, 4], [4, 6, 3, 12]]
输出：[[NaN, NaN, NaN, NaN], [1, 2, NaN, 4], [2, 2, 3, 8], [3, 0, 6, 4]]
```
