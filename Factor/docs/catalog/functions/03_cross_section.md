## 算子详细规格卡片

### <a id="cs_argmax"></a> `cs_argmax(x1)`

- **功能说明**：返回每个交易时点股票截面最大值所在的位置。
- **所属分类**：`cross_section` (截面运算)
- **输入形状契约**：`float64 [T × S] （日期 × 股票）`
- **输出形状契约**：`float64 [T]（date）
从 0 开始的原计算轴位置；不是名次，也不是距当前行的间隔。
FactorLab 最终输出必须保留日期×股票轴；此归约结果不能单独作为最终因子。`
- **滑动窗口要求**：无需滑动窗口
- **缺失值与非有限值处理 (NaN / Inf)**：跳过 NaN 和 Inf；全无有限值输出 NaN；并列极值取原轴上第一个位置，位置从 0 开始。

**参数列表**：

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :---: | :--- |
| `x1` | `matrix` | 是 | `-` | 待计算的 Feature 或表达式矩阵。 |

**调用示例与数值映射**：
```text
cs_argmax(x1)
输入 x1：[[1, 2, NaN, 4], [2, 2, 3, 8], [3, 0, 6, 4], [4, 6, 3, 12]]
输出：[3, 3, 2, 3]
```

- **功能说明**：计算相对均值的平均绝对偏差；不是相对中位数的 MAD。
- **所属分类**：`cross_section` (截面运算)

**参数列表**：

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :---: | :--- |
| `x1` | `matrix` | 是 | `-` | 待计算的 Feature 或表达式矩阵。 |

**调用示例与数值映射**：
```text
cs_mad(x1)
输入 x1：[[1, 2, NaN, 4], [2, 2, 3, 8], [3, 0, 6, 4], [4, 6, 3, 12]]
```
