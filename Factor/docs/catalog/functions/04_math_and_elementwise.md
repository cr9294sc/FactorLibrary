## 算子详细规格卡片

### <a id="abs"></a> `abs(x1)`

- **功能说明**：逐元素取绝对值。
- **所属分类**：`math` (数学变换)
- **输入形状契约**：`float64 [T × S] （日期 × 股票）`
- **输出形状契约**：`float64 [T × S]（date × code）`
- **滑动窗口要求**：无需滑动窗口
- **缺失值与非有限值处理 (NaN / Inf)**：NaN 按逐元素运算传播，不自动填零或剔除；Inf 不主动净化，溢出可产生 Inf。

**参数列表**：

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :---: | :--- |
| `x1` | `matrix` | 是 | `-` | 待计算的 Feature 或表达式矩阵。 |

**调用示例与数值映射**：
```text
abs(x1)
输入 x1：[[1, 2, NaN, 4], [2, 2, 3, 8], [3, 0, 6, 4], [4, 6, 3, 12]]
输出：[[1, 2, NaN, 4], [2, 2, 3, 8], [3, 0, 6, 4], [4, 6, 3, 12]]
```

- **所属分类**：`math` (数学变换)
- **输入形状契约**：`float64 [T × S] （日期 × 股票）`

- **滑动窗口要求**：无需滑动窗口
- **缺失值与非有限值处理 (NaN / Inf)**：数值、下界或上界任一个是 NaN，该位置输出 NaN；否则 min(max(x1,x2),x3)。

**参数列表**：

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :---: | :--- |
| `x1` | `matrix` | 是 | `-` | 待限制范围的数值矩阵。 |
| `x2` | `matrix` | 是 | `-` | 逐元素下界。 |
| `x3` | `matrix` | 是 | `-` | 逐元素上界。 |

**调用示例与数值映射**：
```text
clip(x1,x2,x3)
输入 x1：[[1, 2, NaN, 4], [2, 2, 3, 8], [3, 0, 6, 4], [4, 6, 3, 12]]
输入 x2：[[2.4, 2.8, NaN, 3.6], [2.8, 2.8, 3.2, 5.2], [3.2, 2, 4.4, 3.6], [3.6, 4.4, 3.2, 6.8]]

```

### <a id="perc_long"></a> `perc_long(x1, percentile)`

- **功能说明**：先减去截面分位点，正值保留，负值统一替换为分摊多头总量的负值；输出多空数值。
- **所属分类**：`math` (数学变换)
- **输入形状契约**：`float64 [T × S] （日期 × 股票）`
- **输出形状契约**：`float64 [T × S]（date × code）
正负实数及 0；有限输入时多头总量与空头总量相抵，未经绝对值总和归一化。`
- **滑动窗口要求**：无需滑动窗口
- **缺失值与非有限值处理 (NaN / Inf)**：分位点仅使用有限值；原有 NaN 保留。常数有限截面输出 0；输出不是 0/1 条件矩阵，也不是分位排名。

**参数列表**：

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :---: | :--- |
| `x1` | `matrix` | 是 | `-` | 待计算的 Feature 或表达式矩阵。 |
| `percentile` | `scalar` | 否 | `0.5` | 截面分位点，取值范围为 0 到 1。 |

**调用示例与数值映射**：
```text
perc_long(x1,0.5)
输入 x1：[[1, 2, NaN, 4], [2, 2, 3, 8], [3, 0, 6, 4], [4, 6, 3, 12]]
输出：[[-2, 0, NaN, 2], [-3, -3, 0.5, 5.5], [-1.5, -1.5, 2.5, 0.5], [-4, 1, -4, 7]]
```

### <a id="power"></a> `power(x1, n)`

- **功能说明**：逐元素计算 x1 的 n 次幂。
- **所属分类**：`arithmetic` (逐元素运算)
- **输入形状契约**：`float64 [T × S] （日期 × 股票）`
- **输出形状契约**：`float64 [T × S]（date × code）`
- **滑动窗口要求**：无需滑动窗口
- **缺失值与非有限值处理 (NaN / Inf)**：采用实数幂；负底数的非整数幂通常为 NaN；零的负幂可能为 Inf。n>4 时分拆幂并分别舍入 8 位再相乘。

**参数列表**：

| 参数名 | 类型 | 必填 | 默认值 | 说明 |
| :--- | :--- | :---: | :---: | :--- |
| `x1` | `matrix` | 是 | `-` | 待计算的 Feature 或表达式矩阵。 |
| `n` | `scalar` | 是 | `-` | 幂指数，可为整数或小数。 |

**调用示例与数值映射**：
```text
power(x1,2)
输入 x1：[[1, 2, NaN, 4], [2, 2, 3, 8], [3, 0, 6, 4], [4, 6, 3, 12]]
输出：[[1, 4, NaN, 16], [4, 4, 9, 64], [9, 0, 36, 16], [16, 36, 9, 144]]
```
