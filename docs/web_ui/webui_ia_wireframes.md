# FactorLibrary Web 平台：信息架构与线框图

依据 `2026-11-14-hybrid-research-and-dl-alpha-design.md` §4。参考图①取「白底高密度：左栏 + 指标卡 + PnL 曲线」，参考图②取「右侧 Catalog/算子面板」。

## 1. 信息架构

```
FactorLibrary
├─ 全局顶栏: [期货 Futures | A股 Stocks] · data_version 徽标 · 运行中任务数 · 因子库概览
└─ 路由  #/{market}/{page}      market ∈ futures | stocks
   ├─ P1 data     数据与特征池中心   feature_set / 面板体检 / 1m 扩展包
   ├─ P2 lab      单因子实验室       Catalog + 编辑器 + 探针（升级 tab-ide）
   ├─ P3 compare  诊断与对比看板     Layer1/Layer2 + 2~6 因子 A/B（升级 tab-analytics）
   ├─ P4 mining   挖掘与 DL 训练中心 Recipe 组装 + Run 监控（重构 tab-pipeline）
   └─ P5 registry 因子资产与审核中心 candidate 队列 / 台账 / 三关准入（升级 tab-registry）
```

数据流：`P1 FeatureSet → P4 Recipe(冻结 recipe_id) → CLI 子进程 → candidate → P5 审核 → accepted/active`；`P2` 为单因子捷径入口；`P3` 为 P2/P5 的深入归因出口。
